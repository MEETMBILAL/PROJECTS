# Cursor_Codes — Model Submissions

Each numbered folder holds the **complete generated codebase from one model**
for the same task (the Bookshelf.pk full-stack rebuild), so you can compare
them side by side and grab the code easily.

```
Cursor_Codes/
└── 1/   ← Claude Opus 4.8  (Django REST backend + Next.js 14 frontend)
```

> Note: Only the model that produced this branch could contribute its own
> folder — each agent runs in an isolated sandbox and can only push its own
> output. If you're collecting several models, give each one its own number
> (`1`, `2`, `3`, `4`). Every folder includes an `_INFO.md` identifying the
> model that generated it.
